# ☕ Бот-магазин з каталогом і кошиком

Telegram-магазин: каталог за категоріями, кошик, оформлення замовлення з доставкою Новою Поштою та керування статусами для адміністратора.

## Можливості
- Каталог за категоріями → картка товару з описом і ціною
- Кошик: ➕/➖ кількість прямо в картці чи кошику, очищення, підсумок
- Підказка «до безкоштовної доставки ще N грн»
- Оформлення: ім'я, телефон (кнопкою або вручну, з валідацією), місто й відділення НП
- Адміністратор отримує замовлення з кнопками **Підтвердити / Відправлено / Відхилити**, клієнт автоматично бачить зміну статусу
- `/orders` — останні замовлення
- Кошик і замовлення зберігаються в SQLite (не губляться після перезапуску)

## Стек
Python 3.11+, aiogram 3, SQLite, FSM

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вкажіть BOT_TOKEN і ADMIN_ID
python bot.py
```

Товари редагуються в `catalog.py`. Можна підключити онлайн-оплату через Telegram Payments, LiqPay або Monobank.

# 💈 Бот запису клієнтів (барбершоп / салон / клініка)

Telegram-бот для онлайн-запису на послуги з вибором дати й вільного часу.

## Можливості
- Каталог послуг з ціною та тривалістю
- Вибір дня на тиждень вперед і **тільки вільних** слотів (зайняті та минулі години приховуються)
- Збір імені та телефону (кнопкою «Надіслати номер» або вручну, з валідацією)
- Захист від подвійного запису на один час (унікальний індекс у БД)
- «Мої записи» зі скасуванням
- Миттєві сповіщення адміністратору про нові записи та скасування
- `/admin` — список найближчих записів

## Стек
Python 3.11+, aiogram 3, SQLite, FSM

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вкажіть BOT_TOKEN і ADMIN_ID
python bot.py
```

Послуги та робочі години налаштовуються в `config.py`.

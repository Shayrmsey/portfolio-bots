# 📊 Парсер сайту з вивантаженням в Excel + Telegram-бот

Збирає каталог товарів (демо: навчальний сайт [books.toscrape.com](https://books.toscrape.com)) і віддає красиво оформлений Excel-файл: прямо в Telegram або з командного рядка.

## Можливості
- Парсинг назви, ціни, рейтингу, наявності та посилання з пагінацією
- Excel: стилізований заголовок, автофільтр, закріплений рядок, клікабельні посилання
- Короткий звіт у чаті: кількість, середня ціна, топ найдешевших з рейтингом 5/5
- Бот: `/parse N` або кнопка «Спарсити 5 сторінок», файл приходить документом
- Парсинг у фоновому потоці (бот не «зависає»), захист від повторних запитів, затримка між запитами
- Працює і без бота: `python parser.py --pages 5 --out books.xlsx`

## Стек
Python 3.11+, requests, BeautifulSoup4, openpyxl, aiogram 3

## Запуск
```bash
pip install -r requirements.txt
python parser.py --pages 3          # тільки Excel
cp .env.example .env                # вкажіть BOT_TOKEN
python bot.py                       # бот
```

Під інший сайт змінюється лише функція `parse_page()` у `parser.py`.

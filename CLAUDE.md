## Жёсткие предпочтения

1. **Код без комментариев `#`, без docstring и без лишнего текста внутри кода.** Пояснения — только в чате или README.
2. **Отклики (ставки) — строго в формате полей формы Freelancehunt «Публікація ставки»:**
   - **Коментар:** готовый блок для копирования (контакты запрещены правилами сайта)
   - **Вартість:** число в UAH
   - **Термін виконання:** число дней
   - «Приклад роботи/проєкту» — пропускать (только Plus), «Приховати ставку» — не отмечать, кнопку ИИ-генерации не трогать.
3. Сайт не принимает ставку сильно ниже бюджета заказчика («Ви вказали занадто низький бюджет») — ставить бюджет заказчика или близко к нему.
4. Пользователь не хочет заполнять юридический статус → проекты с меткой **«Бізнес Сейф»** пропускаем.

## Этот репозиторий (`portfolio-bots`)

Четыре самостоятельных демо-бота, у каждого свой `requirements.txt`, `.env.example`, README на украинском:

| Папка | Бот в Telegram | Суть |
|---|---|---|
| `booking_bot/` | @Booking8491057_bot | запись в барбершоп: услуги, свободные слоты, отмена, уведомления админу, `/admin` |
| `shop_bot/` | @Shop39503428603_bot | каталог, корзина ➕/➖, оформление с Новой Почтой, статусы заказа кнопками у админа, `/orders` |
| `leads_bot/` | @leads3285927_bot | заявки → Google Sheets (fallback CSV), FAQ, `/broadcast`, `/stats` |
| `parser_bot/` | @parser69396729467_bot | парсинг books.toscrape.com → стилизованный Excel, `/parse N`; работает и как CLI |

Технически: aiogram 3 (проверено на 3.31), SQLite через `sqlite3`, FSM, HTML parse mode с `html.escape` для пользовательского ввода, `Dispatcher(config=..., db=...)` для DI. Боты в состоянии формы игнорируют тексты кнопок главного меню (`~F.text.in_(MENU_BUTTONS)`), в каждом роутере последний — catch-all `stale_button` для устаревших inline-кнопок.

### Секреты
- Файлы `.env` (токены 4 ботов + `ADMIN_ID` пользователя) **не в git** и при переносе их надо скопировать вручную (или пользователь заново возьмёт токены у @BotFather). Формат: `BOT_TOKEN=<id>:<hash>` — без хвоста `:ABC-your-token` (пользователь однажды так ошибся).
- Не выводить токены в чат.

### Запуск на Linux
```bash
cd portfolio-bots
python3 -m venv .venv
.venv/bin/pip install -r booking_bot/requirements.txt -r leads_bot/requirements.txt -r parser_bot/requirements.txt
cd booking_bot && ../.venv/bin/python bot.py
```
Каждый бот запускается из своей папки (`.env` и `*.db` читаются из текущей директории).

## Как отбирать проекты (договорились)

Брать: свежие (часы, а не дни), до ~15 ставок; Telegram-боты (визитки, запись, заявки, магазин, рассылки, автопостинг, проверка подписки), парсинг одного сайта в Excel/Google Sheets, простые Python-скрипты.

Пропускать: азартные игры/рулетки, бинарные опционы и «сигналы», боты для игр (фермы), мультиаккаунты (OLX и т.п.), сбор баз контактов для спама, 1С/BAS, PHP/Laravel/WordPress, Go, дизайн/лендинги, no-code (Manychat), большие системы (CRM, AI-платформы, маркетплейсы), «Бізнес Сейф».

Перед откликом — просить пользователя прислать вкладку «Обговорення»: там часто ключевые уточнения заказчика, и отклик надо на них ссылаться.

### Шаблон хорошего отклика
1. Обращение по имени.
2. Одна фраза, показывающая, что прочитал задачу/обсуждение.
3. «Як зроблю:» — 3–4 пункта с конкретным техническим решением (показать экспертизу, например «звичайний бот не може читати чужі групи → юзербот»).
4. Что нужно от заказчика / уточняющий вопрос.
5. Срок и цена — в полях формы, не в тексте.

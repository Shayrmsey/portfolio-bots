# 📝 Бот заявок з Google Таблицею та розсилками

Бот для збору заявок від клієнтів (студія, школа, сервіс). Заявки потрапляють у Google Таблицю та одразу приходять менеджеру в Telegram.

## Можливості
- Анкета-заявка: послуга → ім'я → телефон (з валідацією) → коментар
- Запис заявок у **Google Таблицю** (gspread, сервісний акаунт)
- Якщо Google не налаштований або недоступний, заявка зберігається в `leads.csv`, тож жодна не губиться
- Миттєве сповіщення менеджеру з усіма даними та посиланням на клієнта
- FAQ з інлайн-кнопками
- `/broadcast` — розсилка будь-якого повідомлення (текст, фото, відео) всім користувачам з урахуванням лімітів Telegram
- `/stats` — кількість користувачів; ті, хто заблокував бота, автоматично виключаються з розсилок

## Стек
Python 3.11+, aiogram 3, gspread, SQLite, FSM

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вкажіть BOT_TOKEN і ADMIN_ID
python bot.py
```

### Підключення Google Таблиці
1. У Google Cloud Console створіть сервісний акаунт і завантажте ключ як `credentials.json`.
2. Увімкніть Google Sheets API та Google Drive API.
3. Відкрийте доступ до таблиці для email сервісного акаунта (роль «Редактор»).
4. Вкажіть ID таблиці в `.env` → `GOOGLE_SHEET_ID`.
